# Expected control matrix

- `chat-only.md`: named chat source, bounded questions, Draft before approval.
- `conflicting-sources.md`: visible conflict, no invented resolution.
- `bounded-update.md`: confirmed IDs only, ID preservation, reapproval.
- `limit-exceeded.md`: stop and split before drafting.
- `validate-read-only.md`: fresh reviewer, report-only output, unchanged hashes.
- `managed-duplicate-feature.md`: reuse exact duplicate instead of creating a folder.
- `managed-overlap-feature.md`: block overlap for a product-owner decision.
- `knowledge-strategies.md`: preserve strategy-specific paths and exclude scratch by default.
